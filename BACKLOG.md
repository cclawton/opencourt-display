# Backlog

[GitHub Issues](https://github.com/cclawton/opencourt-display/issues) is the source of truth for the OpenCourt product backlog. Use it for bugs, features and investigations; do not maintain a second task list in this file.

The previous outstanding proposals were reviewed and migrated to Issues on 2 November 2026. Completed local-image/slideshow work was not reopened. Club-specific operational tasks belong in the relevant club’s private repository.

Architecture, decisions and operating procedures remain in repository documentation. Older delivery plans describe historical checkpoints, not current issue status. See [Contributing](CONTRIBUTING.md) for the issue workflow.
